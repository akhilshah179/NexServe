# WHY EACH DEPENDENCY:
# - fastapi: The web framework (handles HTTP, routing, validation)
# - uvicorn: ASGI server that runs FastAPI (like a waiter serving requests)
# - sqlalchemy: ORM — maps Python classes to database tables
# - alembic: Database migrations — version control for your DB schema
# - psycopg2-binary: PostgreSQL driver (lets Python talk to PostgreSQL)
# - pydantic-settings: Loads config from .env files with type safety
# - python-jose: Creates and verifies JWT tokens for authentication
# - passlib: Hashes passwords securely (bcrypt algorithm)
# - python-multipart: Handles form data (needed for login forms)
# - redis: Python Redis client for caching
# - celery: Background task queue (send emails, process payments async)
# - httpx: Modern HTTP client (for calling external APIs like Razorpay)
